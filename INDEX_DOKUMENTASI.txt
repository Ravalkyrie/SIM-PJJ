❓ FAQ

Q: Kenapa branch gh-pages muncul?
A: NORMAL! Branch ini dibuat otomatis untuk hosting.
   Baca detail: PENJELASAN_BRANCH_GH_PAGES.txt

Q: Website masih blank setelah setting?
A: Tunggu 2-3 menit lagi, lalu hard refresh (Ctrl+Shift+R)
   Jika masih blank: QUICK_FIX_PAGES_SEKARANG.bat

Q: Perlu deploy ulang setiap update code?
A: Ya, tapi tidak perlu set GitHub Pages lagi (sekali saja!)

Q: Bagaimana cara update website nanti?
A: 1. Edit code
   2. git add . && git commit -m "pesan"
   3. git push origin main
   4. npm run deploy
   5. Tunggu 2-3 menit
