📝 APA YANG HARUS DICARI DI DALAM FILE:
═══════════════════════════════════════════════════════════════════

Cari baris yang berisi salah satu dari ini:

1. Import statement:
   import { createRouter, createWebHistory } from 'vue-router'
   atau
   import { createRouter, createWebHashHistory } from 'vue-router'

2. Router configuration:
   const router = createRouter({
     history: createWebHistory('/SIM-PJJ/'),
     ...
   })
   atau
   history: createWebHashHistory('/SIM-PJJ/')

═══════════════════════════════════════════════════════════════════
✏️ CARA EDIT SETELAH DITEMUKAN:
═══════════════════════════════════════════════════════════════════

UBAH 2 TEMPAT:

1. DI BAGIAN IMPORT (baris paling atas):

   DARI:
   import { createRouter, createWebHistory } from 'vue-router'
   
   KE:
   import { createRouter, createWebHashHistory } from 'vue-router'
   
   (Ubah: createWebHistory → createWebHashHistory)

2. DI BAGIAN ROUTER CONFIG:

   DARI:
   history: createWebHistory('/SIM-PJJ/')
   
   KE:
   history: createWebHashHistory('/SIM-PJJ/')
   
   (Ubah: createWebHistory → createWebHashHistory)

3. SAVE FILE (Ctrl+S)

4. DEPLOY:
   git add .
   git commit -m "Fix: Kembali ke hash router"
   git push origin main
   npm run build
   npm run deploy

💡 CATATAN:
═══════════════════════════════════════════════════════════════════

Jika file router benar-benar tidak ada, kemungkinan:
• Project menggunakan routing library lain (bukan vue-router)
• Router dikonfigurasi di tempat yang tidak standard
• Project menggunakan framework lain (Nuxt, Quasar, dll)

• package.json (dependencies apa yang dipakai)
