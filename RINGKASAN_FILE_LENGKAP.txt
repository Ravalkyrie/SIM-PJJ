   https://ravalkyrie.github.io/SIM-PJJ/#/

   → TIDAK = Lanjut ke langkah 2

LANGKAH 2: Buka Developer Tools (tekan F12)
   • Klik tab "Console"
   • Screenshot semua error yang muncul (merah)
   • Klik tab "Network" 
   • Refresh halaman (Ctrl+Shift+R)
   • Screenshot failed requests (merah)

LANGKAH 3: Pilih solusi (Opsi 1, 2, atau 3 di atas)
