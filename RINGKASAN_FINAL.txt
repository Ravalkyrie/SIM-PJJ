MASALAH:
--------
✗ Halaman blank/kosong di GitHub Pages
✗ URL tanpa # (ravalkyrie.github.io/dashboard) → Error 404
✗ Refresh halaman → Error 404


PENYEBAB:
---------
GitHub Pages adalah static hosting yang tidak bisa handle routing
dinamis. Ketika mengakses /dashboard, GitHub Pages mencari file
dashboard/index.html yang tidak ada.


SOLUSI LENGKAP:
---------------

1. ✓ App.tsx (Baris 7)
   - Sudah diubah dari BrowserRouter ke HashRouter
   - import { HashRouter as Router, ... }

2. ✓ public/404.html
   - File ini akan ditampilkan GitHub Pages saat file tidak ditemukan
   - Berisi script redirect: /dashboard → /?/dashboard

3. ✓ index.html (Baris 20-34)
   - Ditambah script untuk convert: /?/dashboard → /#/dashboard
   - Script berjalan sebelum React dimuat

4. ✓ vite.config.ts
   - base: '/SIM-PJJ/' sudah benar
   - Build akan generate path yang benar


CARA KERJA:
-----------
User akses → ravalkyrie.github.io/dashboard (tanpa #)
    ↓
404.html → redirect ke /?/dashboard
    ↓
index.html → script convert ke /#/dashboard
    ↓
HashRouter → handle routing dan render halaman

TROUBLESHOOTING:
----------------

Jika masih error 404 setelah deploy:

1. Hard Refresh
   - Ctrl+F5 atau Ctrl+Shift+R
   - Paksa browser download file terbaru

2. Clear Browser Cache
   - Chrome: Ctrl+Shift+Delete
   - Pilih "Cached images and files"
   - Clear data

3. Gunakan Incognito Mode
   - Chrome: Ctrl+Shift+N
   - Firefox: Ctrl+Shift+P
   - Test tanpa cache

4. Tunggu Lebih Lama
   - Kadang GitHub Pages butuh 5-10 menit
   - Coba akses lagi setelah beberapa menit

5. Cek File di GitHub
   - Buka: https://github.com/Ravalkyrie/SIM-PJJ/tree/gh-pages
   - Pastikan ada file: 404.html, index.html
   - Cek isi 404.html apakah berisi script redirect

6. Test Langsung dengan #
   - Akses: https://ravalkyrie.github.io/SIM-PJJ/#/
   - Jika ini berhasil, berarti HashRouter sudah bekerja

MENGAPA HASHROUTER:
-------------------
- BrowserRouter butuh server dengan dynamic routing
- GitHub Pages hanya static hosting
- HashRouter handle routing di browser (client-side)
- URL dengan # tidak dikirim ke server
- Semua routing di-handle oleh JavaScript


PERBANDINGAN:
-------------
SEBELUM (BrowserRouter):
  URL: ravalkyrie.github.io/dashboard
  GitHub Pages: Cari file /dashboard/index.html → NOT FOUND (404)

SESUDAH (HashRouter):
  URL: ravalkyrie.github.io/#/dashboard
  Browser: Handle routing pakai JavaScript
  GitHub Pages: Hanya serve index.html sekali
  React Router: Handle route /#/dashboard
