║     FIX GITHUB PAGES MASIH BLANK SETELAH DEPLOY               ║
╚════════════════════════════════════════════════════════════════╝

PROBLEM:
✗ Setelah npm run deploy, website masih blank/error
✗ Branch gh-pages sudah ada tapi tidak ditampilkan
✗ Error: "Security Error: Content may not load"

PENYEBAB:
- GitHub Pages settings belum dikonfigurasi untuk menggunakan branch gh-pages
- Atau masih mengarah ke folder/branch yang salah

═══════════════════════════════════════════════════════════════════

📌 LANGKAH 1: SETTING GITHUB PAGES (WAJIB!)

1. Buka browser, ke: https://github.com/Ravalkyrie/SIM-PJJ/settings/pages

2. Di bagian "Build and deployment":
   ┌────────────────────────────────────────┐
   │ Source: Deploy from a branch          │
   │                                        │
   │ Branch: [gh-pages ▼] / [root ▼] [Save]│
   └────────────────────────────────────────┘

3. Pilih:
   ✓ Branch: gh-pages
   ✓ Folder: / (root)
   
4. Klik tombol [Save]

5. Tunggu 2-3 menit, lalu refresh

═══════════════════════════════════════════════════════════════════

📌 LANGKAH 2: VERIFIKASI DEPLOYMENT

Setelah save, kamu akan lihat notifikasi di atas:
"Your site is live at https://ravalkyrie.github.io/SIM-PJJ/"

Tunggu proses deployment selesai (ada indicator loading).

═══════════════════════════════════════════════════════════════════

📌 JIKA MASIH BLANK - FORCE REDEPLOY

Jalankan di terminal (Git Bash atau PowerShell):

cd "C:\New folder\Manajemen"
npm run build
npm run deploy

Ini akan force push ulang ke gh-pages branch.

═══════════════════════════════════════════════════════════════════

📌 JIKA MASIH ERROR - CEK BASE URL

Buka file: vite.config.js

Pastikan ada setting ini:

export default defineConfig({
  base: '/SIM-PJJ/',  // ← Harus sama dengan nama repo
  // ... config lainnya
})

Jika tidak ada atau salah, edit lalu deploy ulang.

═══════════════════════════════════════════════════════════════════

✅ CARA CEK BERHASIL:

1. Buka: https://ravalkyrie.github.io/SIM-PJJ/
2. Website sudah tampil dengan logo (dari seeklogo.com)
3. Tidak ada error di console browser (F12)

═══════════════════════════════════════════════════════════════════

🔍 TROUBLESHOOTING TAMBAHAN:

Problem: Error "may not load" 
Fix: Pastikan base URL di vite.config.js benar

Problem: 404 Not Found
Fix: Tunggu 5 menit, GitHub Pages butuh waktu propagasi

Problem: CSS tidak load
Fix: Base URL salah, harus '/SIM-PJJ/' bukan '/SIM-PJJ' atau '/'

Problem: Branch gh-pages tidak muncul di dropdown
Fix: Refresh halaman settings, atau wait 1-2 menit
