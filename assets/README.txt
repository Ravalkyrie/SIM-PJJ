# Hero Background Image Setup

## Required Image
Save the bridge/highway image as: hero-bridge.jpg

## Steps:
1. Save the provided bridge/highway image to this folder as "hero-bridge.jpg"
2. The image will automatically be used as the hero section background
3. Recommended image specifications:
   - Format: JPG
   - Dimensions: 1920x600 pixels (or similar wide aspect ratio)
   - Quality: High quality for professional appearance
   - Subject: Highway/bridge infrastructure

## Current Implementation
The DashboardView component now uses this image with a dark overlay for text readability.
