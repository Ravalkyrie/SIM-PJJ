═══════════════════════════════════════════════════════════════════
🔧 SOLUSI 1: KEMBALI KE HASH ROUTER (CEPAT & MUDAH)
═══════════════════════════════════════════════════════════════════

File: src/router/index.js atau src/router/index.ts

UBAH DARI:
```javascript
import { createRouter, createWebHistory } from 'vue-router'

const router = createRouter({
  history: createWebHistory('/SIM-PJJ/'),
  routes: [...]
})
```

UBAH KE:
```javascript
import { createRouter, createWebHashHistory } from 'vue-router'

const router = createRouter({
  history: createWebHashHistory('/SIM-PJJ/'),
  routes: [...]
})
```

LANGKAH DEPLOY:
1. Ubah router ke createWebHashHistory
2. git add .
3. git commit -m "Fix: Kembali ke hash router untuk GitHub Pages"
4. git push origin main
5. npm run build
6. npm run deploy
7. Tunggu 2-3 menit
8. Test: https://ravalkyrie.github.io/SIM-PJJ/#/kontrak

═══════════════════════════════════════════════════════════════════
🔧 SOLUSI 2: HISTORY ROUTER + 404 TRICK (KOMPLEKS)
═══════════════════════════════════════════════════════════════════

Jika ingin tetap pakai History Router tanpa #, perlu:

1. Buat file 404.html di folder public:
```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8">
    <title>SIM-PJJ</title>
    <script>
      // GitHub Pages 404 redirect trick
      sessionStorage.redirect = location.href;
    </script>
    <meta http-equiv="refresh" content="0;URL='/SIM-PJJ/'">
  </head>
  <body>
  </body>
</html>
```

2. Update index.html (tambahkan di <head>):
```html
<script>
  // GitHub Pages redirect handling
  (function(){
    var redirect = sessionStorage.redirect;
    delete sessionStorage.redirect;
    if (redirect && redirect != location.href) {
      history.replaceState(null, null, redirect);
    }
  })();
</script>
```

3. Deploy ulang

KEKURANGAN SOLUSI INI:
- Lebih kompleks
- SEO tidak optimal
- Refresh page akan flash redirect
- Tidak direkomendasikan untuk production
